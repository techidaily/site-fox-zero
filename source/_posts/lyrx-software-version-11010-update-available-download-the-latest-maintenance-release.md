## LYRX Software Version 1.10.1.0 Update Available: Download the Latest Maintenance Release

[![LYRX 1.10.1.0 Update](https://i2.wp.com/pcdj.com/wp-content/uploads/2023/06/lyrx-1.10.1.0-update.jpg?resize=845%2C321&ssl=1)](https://i2.wp.com/pcdj.com/wp-content/uploads/2023/06/lyrx-1.10.1.0-update.jpg?fit=1030%2C603&ssl=1 "lyrx-1.10.1.0-update")

Announcing the new 1.10.1.0 release of [LYRX](http://www.lyrxkaraoke.com/), our top-tier karaoke software solution specially designed for professional karaoke hosts. This new release comes with an array of bug fixes and improvements, enhancing your LYRX experience, ensuring smooth and uninterrupted performances every time.

[![LYRX1.10 with Vocal Eliminator "Kill Vocal"](https://i2.wp.com/pcdj.com/wp-content/uploads/2023/04/LYRX1.10-1.png?resize=311%2C171&ssl=1)](http://www.lyrxkaraoke.com/)

The most notable updates in this release include a fix to the RememberSongEq bug, ensuring your custom song settings are properly saved and recalled. In addition, the update resolves an issue with the next singers list on the video screen, where it was doubling the last singer when “Show Empty Singers” was enabled with not enough singers in the list. This fix will provide a smoother, more accurate visual cue for the upcoming singer rotation.

Furthermore, we’ve addressed and resolved the Karaoke Cloud Pro (KCP) subscriptions bug, guaranteeing seamless access and experience for all our KCP subscribers. We also worked diligently to fix higher CPU utilization and audio drop-outs for LYRX, so you can host your karaoke sessions without any unwanted interruptions or technical hiccups (an issue some reported with the previous 1.10 release).

Apart from these critical fixes, this LYRX release also includes numerous minor improvements that contribute to a more streamlined and improved overall user experience. As always, we are committed to providing the best possible karaoke software solutions for professional karaoke hosts, and we are confident this new LYRX release delivers exactly that.
